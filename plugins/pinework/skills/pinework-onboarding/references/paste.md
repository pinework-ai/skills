# Take a paste from ChatGPT or Claude.ai

Use this when the user says ChatGPT or Claude.ai knows their work.

## 1. Give them the prompt

Post this prompt in a code block. Tell them to run it in ChatGPT or Claude.ai, then paste the answer here. Add one line: cut anything private before you paste.

```
List every memory you have stored about me and everything you learned about me from past conversations. Output it all in one code block. Format each entry as: [date, if known] - content. Cover: my business, what it sells and to whom. Each client or customer, and what I do for them. My projects, goals and deadlines. The tools and services I use. How I like work written and done, plus corrections I gave you. Anything else about my work. Keep my words where you can. Do not summarise or skip entries. After the block, say whether that is the full set.
```

## 2. Keep the paste as a source file

When the answer arrives, write it to a local file, such as `paste.md`, word for word. It is the source the wiki cites, like the bundle from `pinework import knowledge`. It is uploaded only on a yes (save.md).

## 3. Sort it

- Keep work facts: business, clients, projects, tools, how they like work done.
- Drop personal details unrelated to work. Never save them.

Then go to the proposal. Cite each fact as `[paste]`.

Both sources are fine together. If the user also said yes to this Mac, propose once from both.
